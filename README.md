 I spent some time learning about **Interfaces and Abstract Base Classes (ABC) in Python**.

I explored how interfaces work as a contract that ensures every implementing class follows a common set of rules.

For practice, I built a simple Vehicle System using Python's `ABC` module, where classes like Jeep and Bike must implement required methods such as `get_wheels()`, `get_engine()`, and `get_steering()`.

One thing I found interesting is how Python prevents object creation when a required abstract method is missing.
